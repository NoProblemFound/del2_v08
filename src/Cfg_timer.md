## Ändra tid på timer
### User Story
Som användare vill jag kunna ändra tidsinställningen för en timer, 
så att jag kan anpassa tiden efter mina behov.

## Acceptanskriterier
1. Användaren ska kunna öppna inställningarna för tiden genom att klicka på kugghjulet.
2. Användaren ska kunna ange en ny tid för timern.
3. När användaren sparar den nya tiden ska timern visa den valda tiden.
4. När timern startas ska nedräkningen börja från den nya tiden.
