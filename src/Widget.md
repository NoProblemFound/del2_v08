## Lägga till och ta bort widget
### User Story
Som en användare vill jag kunna lägga till och ta bort timer- och anteckningswidget, så att jag kan anpassa websidan
efter mina behov.

## Acceptanskriterier
1. När användaren klickar på Add timer ska en timerwidget skapas.
2. När användaren klickar på Add note ska en anteckningswidget skapas.
3. När användaren klickar på soptunneikonen för en timerwidget ska timerwidgeten tas bort.
4. När användaren klickar på soptunneikonen för en anteckningswidget ska anteckningswidgeten tas bort.


## Testscenario 
### Skapa timerwidget
Gå till webbplatsen.
Klicka på Add timer.
Kontrollera att en ny timerwidget visas.

### Skapa anteckningswidget
Gå till webbsidan.
Klicka på Add note.
Kontrollera att en anteckningswidget visas.


### Ta bort timerwidget
Gå till webbsidan.
Klicka på Add timer.
Klicka på widgetens soptunnsikon.
Kontrollera att timerwidgeten inte längre visas.

### Ta bort anteckningswidget
Gå till websiddan.
Klicka på Add note.
Klicka på widgetens soptunnaikon.
Kontrollera att anteckningswidgeten inte längre visas.
