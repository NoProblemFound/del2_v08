## Ändra temafärg
### User Story
Som en användare vill jag kunna byta färgtema på webbsidan, så att jag kan välja det utseende jag gillar bäst.

## Acceptanskriterier
- AK1 Användaren ska kunna välja temat Light.
- AK2 Användaren ska kunna välja temat Dark.
- AK3 Användaren ska kunna välja temat Forest.
- AK4 Användaren ska kunna välja temat Orange.
- AK5 Användaren ska kunna välja temat Christmas.
- AK6 När användaren väljer ett tema ska sidans färger ändras direkt.

## Testscenario
### Scenario 1: Byta till Light-tema
Gå till webbplatsen.
Klicka på knappen Light.
Kontrollera att sidan visas med ljust tema

### Scenario 2: Byta till Dark-tema
Gå till webbplatsen.
Klicka på knappen Dark.
Kontrollera att sidan visas med mörkt tema

### Scenario 3: Byta till Forest-tema
Gå till webbplatsen.
Klicka på knappen Forest.
Kontrollera att Forest-temat blir aktivt.
Kontrollera att sidan visas med grönt tema

### Scenario 4: Byta till Orange-tema
Gå till webbplatsen.
Klicka på knappen Orange.
Kontrollera att sidan visas med orangefärgat tema

### Scenario 5: Byta till Christmas-tema
Gå till webbplatsen.
Klicka på knappen Christmas.
Kontrollera att Christmas-temat blir aktivt.
Kontrollera att sidan visas med jul tema
